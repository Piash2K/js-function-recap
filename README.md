

# JS Function Recap

A collection of JavaScript examples and explanations to recap common function-related concepts: parameters, arguments, return values, function definitions, conditionals, and utility patterns. Useful for learners, revision, or quick reference.

---

## 📚 What’s Inside

This repo includes standalone JS files, each covering a specific aspect of JavaScript functions:

* `function.js` — basic function definition & invocation
* `return.js` — using return values from functions
* `parameter.js` — function parameters and default values
* `arguments.js` — handling arguments dynamically
* `various-params.js` — functions with varying numbers/types of parameters
* `conditional.js` — using control flow inside functions
* `recap.js` — a summary file / combined examples

---

## ✅ Why This Repo

This repo aims to help developers and learners:

* Brush up JS function fundamentals
* Reference different function-related use cases quickly
* Understand how parameters, arguments, returns, and conditionals work in pure JS
* Use simple, minimal, and readable code examples

---

## 🧰 Usage

Just clone the repo and open any file in your favorite code editor or run them via Node.js. For example:

```bash
git clone https://github.com/Piash2K/js-function-recap.git  
cd js-function-recap  

# To run a file
node function.js  
# or
node return.js  
```

Feel free to read, experiment, and learn.
